# Student Registration System

A beginner-friendly registration form built for Cognifyz Full Stack Development Internship — Task 1. It uses Node.js and Express to handle requests, and EJS to render the form and registration result on the server.

## Requirements

- Node.js 18 or newer (includes npm)
- A web browser

To check that Node.js and npm are installed, open PowerShell or Command Prompt and run:

```powershell
node --version
npm --version
```

## Install and run on Windows

1. Open PowerShell or Command Prompt.
2. Change to the project folder. For the current workspace, run:

   ```powershell
   cd "$HOME\OneDrive\Desktop\Cognifyz_FullStack"
   ```

   If you saved the project elsewhere, replace that path with your project folder's path.
3. Install the dependencies:

   ```powershell
   npm install
   ```

4. Start the web server:

   ```powershell
   npm start
   ```

5. Open **http://localhost:3000** in your browser. Keep the terminal open while using the app. Press **Ctrl+C** in that terminal to stop the server.

`npm install` downloads Express and EJS and creates `package-lock.json`. On later runs, you only need `npm start`.

## Test it in a browser

1. Visit **http://localhost:3000**.
2. Submit the form with a name, valid email address, and department. The confirmation page should display all three values.
3. Click **Register another student** to return to the form.
4. Try leaving a field blank. The browser's required-field validation should stop the submission. Server-side validation also checks required values, the email format, and that the department is one of the listed choices; these checks can be observed if a request bypasses the browser's checks.
5. The form does not save registrations. Submitted details are rendered in the response only.

## How the code works

### `server.js`

- Creates the Express app, tells Express to use EJS templates in `views`, serves browser assets from `public`, and uses `express.urlencoded()` to read standard HTML form submissions.
- `GET /` renders the form and supplies the department list, blank initial values, and an empty error list.
- `POST /register` reads and trims the form fields. It validates that name and email are present, checks the email's basic format, and accepts only a department from the provided list. If anything is invalid, it responds with HTTP 400 and re-renders the form with messages and the entered values. Otherwise, it renders the result page with the submitted student information.
- EJS's `<%= ... %>` output tags HTML-escape submitted values, preventing them from being interpreted as markup in the rendered page.
- The app listens on port `3000` by default. A `PORT` environment variable can override it.

### `views/index.ejs`

Contains the HTML form. Its `action="/register"` and `method="POST"` send the fields to the Express endpoint. The `required` attributes and `type="email"` provide convenient browser-side validation; the server repeats important checks because browser validation alone is not sufficient. EJS inserts validation messages and restores submitted values after an invalid request.

### `views/result.ejs`

Displays the successfully submitted name, email, and department. It is a server-rendered response, not a separate client-side JavaScript page.

### `public/styles.css`

Styles the form, validation notice, and result page. Express makes it available at `/styles.css` through its static-file middleware.

### `package.json` and `.gitignore`

`package.json` declares Express and EJS and defines `npm start`. `.gitignore` keeps installed dependencies and local environment files out of source control.

## Notes

This is a learning demo: it does not use a database, authentication, or persistent storage. The email validation is intentionally basic and is not a substitute for a verification email in a production system.
